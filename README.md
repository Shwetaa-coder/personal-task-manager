# Personal Task Manager

A full-stack task management application developed using React, Java Spring Boot, and PostgreSQL.

## Project Structure

- **Taskmanager:** Spring Boot backend with REST APIs.
- **Personal Task Manager Frontend:** React frontend built using Vite.

## Features

- Create, edit and delete tasks.
- Mark tasks as completed or pending.
- Set task priorities.
- Add descriptions and due dates.
- Search and filter tasks.
- Store tasks in PostgreSQL.

## Technologies

- Java
- Spring Boot
- React
- JavaScript
- PostgreSQL
- Maven
- Vite

## Project Status

Core functionality implemented and tested locally.
